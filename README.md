# Courses TV

[![CI](https://github.com/dshpet/courses-tv/actions/workflows/ci.yml/badge.svg)](https://github.com/dshpet/courses-tv/actions/workflows/ci.yml)

An unofficial Android TV app for a [The Great Courses Plus](https://plus.thegreatcourses.com/)
subscription, made for the Chromecast with Google TV. Runs on Google TV and Android TV, Android 14+.

> **Unofficial.** Not affiliated with, endorsed by or sponsored by The Teaching Company, LLC.
> "The Great Courses" and "The Great Courses Plus" are its trademarks. You need your own
> subscription: the app plays only what your account can play, streams it as the website does and
> downloads no lectures.

Home, Search, Subjects, My List, course pages with guidebooks and professors, and a player with
captions, quality and speed. Screens are native and use the service's JSON API with your website
session: you sign in through the website's own dialog, and the app stores no password or token.
Progress is saved to your account, so the website and phone app continue from the same place.

Built with Jetpack Compose for TV, Media3, Coil and OkHttp.

## Progress

- A lecture counts as started after 2 minutes and finished at 90%. A finished lecture played again
  stays finished.
- Continue Watching has one card per course, at the lecture after the furthest finished one:
  courses watched in the last 16 weeks, at most 10, finished courses left out.
- After three lectures autoplay with no button pressed, the next waits behind "Are you still
  watching?".

## Remote

| Where | Keys | Action |
| --- | --- | --- |
| Continue Watching card | Select held | Play, Play from the beginning, Go to course, Remove |
| Lecture in a course | Select held | Play, Play from the beginning, Mark as watched / not watched |
| Course | Down from Play | To the lecture Play would play |
| Player | Left/Right (held: faster) | Seek 10 s (30 s) |
| Player | Down | Lectures, Captions, Settings (quality, speed, caption size), Next lecture |
| Sign-in | Select on a field; Back | Open the keyboard; close it, then the dialog |

## Build and install

1. Build with Android Studio, or JDK 17+ and the Android SDK with platform 37:

   ```sh
   ./gradlew assembleRelease
   ```

2. On the TV: Settings → System → About, press Select on *Android TV OS build* seven times; then
   Developer options → *Wireless debugging* → *Pair device with pairing code*.

3. Pair, install, and compile ahead of time (Compose is slow until compiled):

   ```sh
   adb pair <ip>:<port>
   adb connect <ip>:<port>
   adb install -r app/build/outputs/apk/release/app-release.apk
   adb shell cmd package compile -m speed -f io.github.dshpet.coursestv
   ```

Release builds are signed with `app/sideload.keystore` (a copy of a debug keystore, git-ignored) if
present, else the local debug key; keep one key so updates install. `assembleReadOnly` builds a
release app that sends no changes to the account.

## Test

```sh
./gradlew testDebugUnitTest
node --test tests/site.test.cjs     # Node 22+, headless Chromium (/usr/bin/chromium or CHROMIUM=)
```

Manual TV checks: [tests/EMULATOR_CHECKS.md](tests/EMULATOR_CHECKS.md).

## Limits

- The API routes and stream links are undocumented and can change.
- Remove from Continue Watching uses the website's Remove and can't be undone.
- Search covers course titles and descriptions, not lectures.
- Recommendations and banners aren't shown.
